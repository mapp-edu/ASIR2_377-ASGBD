# ✅ Cuestionario de autoevaluación

Comprueba lo que has aprendido en la unidad. Piensa la respuesta antes de desplegar la solución.

## Oracle y PostgreSQL

**1. ¿Cuál de las siguientes no es una herramienta de monitorización?**

- a) El diccionario de datos
- b) El log de ejecución
- c) El monitor de rendimiento
- d) El plan de ejecución

::: details Ver respuesta
d) El plan de ejecución
:::

**2. ¿Cuál de las siguientes no es una función del monitor de rendimiento?**

- a) Detección de bloqueos
- b) Detección de procesos acaparadores
- c) Seguimiento de métricas
- d) Generación del plan de ejecución

::: details Ver respuesta
d) Generación del plan de ejecución
:::

**3. En el diccionario de datos se pueden comprobar las consultas (pesadas) que se están ejecutando:**

- a) Falso
- b) Verdadero

::: details Ver respuesta
b) Verdadero
:::

**4. En el diccionario de datos se pueden comprobar los bloqueos activos:**

- a) Falso
- b) Verdadero

::: details Ver respuesta
b) Verdadero
:::

**5. En el diccionario de datos se puede consultar quién está conectado y qué ejecuta:**

- a) Falso
- b) Verdadero

::: details Ver respuesta
b) Verdadero
:::

**6. ¿Por qué es necesario actualizar las estadísticas?**

- a) Se usan para comprimir las tablas
- b) Se usan para optimizar las consultas
- c) Se usan para optimizar el espacio de almacenamiento
- d) Se usan para crear el plan de ejecución de las consultas

::: details Ver respuesta
d) Se usan para crear el plan de ejecución de las consultas
:::
