# 🧪 Prácticas y ejercicios

Actividades de la **UT1 · Implantación de sistemas gestores de bases de datos**, asociadas al **RA1** (5 % de la nota del módulo).

Las prácticas 1 a 5 siguen un orden: primero se preparan las máquinas virtuales, después se despliegan los SGBD y por último los clientes. La práctica 6 (selección del SGBD) no depende de las instalaciones y puede hacerse en cualquier momento.

## Prácticas evaluables

Cada práctica incluye su enunciado, el entregable y la rúbrica.

| Actividad | Descripción |
|:---|:---|
| [Práctica 1: preparación de la MV Linux Mint](./practica-1-mv-linux-mint) | Crear la máquina virtual Linux que servirá de servidor para las prácticas. |
| [Práctica 2: desplegar Oracle, PostgreSQL y MariaDB](./practica-2-tres-sgbd) | Instalar tres SGBD en la MV servidor, crear una base de datos y un usuario en cada uno y abrir el acceso remoto. |
| [Práctica 3: instalar los clientes de los tres SGBD](./practica-3-clientes) | Instalar en una máquina distinta los clientes gráficos y de terminal de Oracle, PostgreSQL y MariaDB. |
| [Práctica 4: preparación de la MV Windows 10 Pro](./practica-4-mv-windows-10) | Crear la máquina virtual Windows sobre la que se instalará Oracle 21c. |
| [Práctica 5: instalar Oracle 21c en Windows 10 Pro](./practica-5-oracle-21c-windows) | Instalar el software de Oracle 21c, crear dos bases de datos multitenant, configurar el listener y conectar con SQL Developer. |
| [Práctica 6: selección del SGBD](./practica-6-seleccion-sgbd) | Analizar tres casos reales y elegir, de forma razonada, el SGBD más adecuado para cada uno. |
