# ✅ Cuestionario de autoevaluación

Comprueba lo que has aprendido en la unidad. Piensa la respuesta antes de desplegar la solución.

## Oracle

**1. ¿Cuál es una de las principales ventajas de la automatización en una empresa?**

- a) Aumento del trabajo manual
- b) Ahorro de tiempo en los procesos
- c) Incremento de los errores humanos
- d) Dependencia exclusiva de los trabajadores

::: details Ver respuesta
b) Ahorro de tiempo en los procesos
:::

**2. ¿Qué herramienta se utiliza habitualmente en Linux para programar tareas externas?**

- a) Task Scheduler
- b) Crontab
- c) SQL Job
- d) Trigger

::: details Ver respuesta
b) Crontab
:::

**3. PL/SQL**

- a) Es un lenguaje procedimental
- b) Es un lenguaje declarativo
- c) No tiene estructuras de control como bucles o condiciones complejas
- d) No permite utilizar variables

::: details Ver respuesta
a) Es un lenguaje procedimental
:::

**4. Dentro de un procedimiento no se pueden ejecutar sentencias DDL directamente**

- a) Falso
- b) Verdadero

::: details Ver respuesta
b) Verdadero
:::

**5. Cuando se ejecuta un trigger, si no se ha indicado nada en FOR EACH, ¿cuántas veces se ejecuta?**

- a) Ninguna
- b) Una o más veces
- c) Más de una vez
- d) Solo una vez

::: details Ver respuesta
d) Solo una vez
:::

**6. En Oracle DBMS_SCHEDULER, si no se indica la hora (BYHOUR) en el REPEAT_INTERVAL, se utiliza la primera hora del día, las 00:00**

- a) Falso
- b) Verdadero

::: details Ver respuesta
a) Falso
:::

**7. Una vez creado un job, ya no se pueden modificar sus atributos**

- a) Falso
- b) Verdadero

::: details Ver respuesta
a) Falso
:::
