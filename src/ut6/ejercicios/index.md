# 🧪 Prácticas y ejercicios

Actividades de la **UT6 · Disponibilidad: bases de datos distribuidas y replicadas**, asociadas al **RA6** (10 % de la nota del módulo).

Entre las tres prácticas se cubren todos los criterios de evaluación del RA6: una base de datos distribuida diseñada desde cero, otra creada integrando bases de datos que ya existían y un sistema replicado con maestro, esclavos y réplica en cadena.

## Prácticas evaluables

Cada práctica incluye su enunciado, el entregable y la rúbrica.

| Actividad | Descripción |
|:---|:---|
| [Práctica 1: base de datos distribuida y fragmentación](./practica-1-base-de-datos-distribuida) | Implantar una base de datos distribuida homogénea con fragmentación horizontal y vertical entre varios nodos. |
| [Práctica 2: integración de bases de datos preexistentes](./practica-2-integracion-de-bases-de-datos) | Crear una base de datos distribuida a partir de dos bases de datos que ya existían y tienen esquemas distintos. |
| [Práctica 3: replicación maestro-esclavo y en cadena](./practica-3-replicacion) | Configurar un nodo maestro con varios esclavos, añadir una réplica en cadena y comprobar el efecto de parar cada nodo. |

## Autoevaluación

| Actividad | Descripción |
|:---|:---|
