# ✅ Cuestionario de autoevaluación

Comprueba lo que has aprendido en la unidad. Piensa la respuesta antes de desplegar la solución.

## Oracle RAC y la nube

**1. ¿Cuál es la función principal de Oracle RAC?**

- a) Hacer copias de seguridad automáticas
- b) Permitir el acceso concurrente a una base de datos compartida
- c) Mejorar la seguridad de las contraseñas
- d) Optimizar consultas SQL individuales

::: details Ver respuesta
b) Permitir el acceso concurrente a una base de datos compartida
:::

**2. ¿Qué pasa si un nodo falla en un entorno RAC?**

- a) El sistema se para completamente
- b) Se pierde la base de datos
- c) Otro nodo asume la carga automáticamente
- d) Hay que reiniciar manualmente el sistema

::: details Ver respuesta
c) Otro nodo asume la carga automáticamente
:::

**3. ¿Cuál de los siguientes es un componente necesario en Oracle RAC?**

- a) Un único servidor independiente
- b) Red wifi pública
- c) Red de interconexión entre nodos
- d) Disco duro externo USB

::: details Ver respuesta
c) Red de interconexión entre nodos
:::

**4. ¿Cuál es una de las principales ventajas de Oracle RAC?**

- a) Reducción total de costes
- b) Eliminación de la necesidad de mantenimiento
- c) Escalabilidad dinámica
- d) Funciona sin red

::: details Ver respuesta
c) Escalabilidad dinámica
:::

**5. ¿Cuál de las siguientes es una alternativa a Oracle RAC?**

- a) Apache Hadoop
- b) Docker Swarm
- c) Microsoft SQL Server AlwaysOn
- d) MongoDB Compass

::: details Ver respuesta
c) Microsoft SQL Server AlwaysOn
:::

**6. ¿Qué representa la nube en el contexto de los SGBD?**

- a) Un tipo de base de datos local
- b) Una tecnología para utilizar infraestructuras virtuales
- c) Un sistema operativo especializado
- d) Un lenguaje de programación

::: details Ver respuesta
b) Una tecnología para utilizar infraestructuras virtuales
:::

**7. ¿Cuál es una ventaja de la nube?**

- a) Necesita grandes inversiones iniciales
- b) No permite el acceso remoto
- c) Pago por uso más eficiente
- d) Elimina la necesidad de internet

::: details Ver respuesta
c) Pago por uso más eficiente
:::

**8. ¿Cuál es un inconveniente de la nube?**

- a) Alta disponibilidad
- b) Dependencia de un proveedor externo
- c) Escalabilidad automática
- d) Acceso remoto desde cualquier lugar

::: details Ver respuesta
b) Dependencia de un proveedor externo
:::

**9. ¿Cuál de los siguientes es un proveedor de nube?**

- a) Linux Server
- b) AWS (Amazon Web Services)
- c) Apache
- d) Docker

::: details Ver respuesta
b) AWS (Amazon Web Services)
:::

**10. ¿Qué ofrecen las plataformas de nube para SGBD?**

- a) Solo almacenamiento local
- b) Monitorización en tiempo real y copias automáticas
- c) Únicamente acceso offline
- d) Eliminación de la seguridad

::: details Ver respuesta
b) Monitorización en tiempo real y copias automáticas
:::
